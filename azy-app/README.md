# Azy — مسارك الدراسي

تطبيق موبايل (React Native / Expo) يساعد الطالب الكويتي المبتعث على متابعة رحلته الدراسية بالخارج: الجامعات، المستندات، خطوات الابتعاث، اختبارات اللغة، والتدريب.

## تشغيل التطبيق على جوالك (الطريقة الأسرع)

1. ثبّت تطبيق **Expo Go** من App Store أو Google Play على جوالك.
2. على جهازك (لابتوب/كمبيوتر) ثبّت الاعتماديات:
   ```bash
   npm install
   ```
3. شغّل خادم التطوير:
   ```bash
   npx expo start
   ```
4. امسح رمز QR الظاهر في الطرفية أو المتصفح باستخدام تطبيق **Expo Go** (أندرويد: كاميرا Expo Go، آيفون: كاميرا الجوال العادية).
5. التطبيق بيفتح على جوالك مباشرة، وأي تعديل بالكود ينعكس تلقائياً (Fast Refresh).

> ملاحظة: جوالك واللابتوب لازم يكونون على نفس شبكة الواي فاي.

## بناء نسخة حقيقية قابلة للتثبيت (APK / IPA)

عشان يصير عندك تطبيق مستقل تقدر تثبته بدون Expo Go — أو تنزّله على متجر التطبيقات — استخدم **EAS Build**:

```bash
npm install -g eas-cli
eas login
eas build:configure
```

### أندرويد (ملف APK يثبت مباشرة على أي جوال أندرويد)
```bash
eas build --platform android --profile preview
```
بعد ما يخلص البناء بيعطيك رابط تحميل لملف APK — نزّله على جوالك وثبّته مباشرة.

### آيفون (يحتاج حساب Apple Developer)
```bash
eas build --platform ios --profile preview
```

### نشر على المتاجر الرسمية (Google Play / App Store)
```bash
eas build --platform android --profile production
eas build --platform ios --profile production
eas submit --platform android
eas submit --platform ios
```

## هيكلة المشروع

```
App.js          # الشاشة الرئيسية وكل مكونات الواجهة
app.json        # إعدادات Expo (الاسم، الأيقونة، شاشة البداية، الصلاحيات)
eas.json        # إعدادات بناء EAS (development / preview / production)
assets/         # الأيقونة وشاشة البداية
```

## الحالة الحالية للميزات

| الميزة | الحالة |
|---|---|
| تصوير المستندات بالكاميرا | ✅ يعمل فعلياً (expo-camera) — التحويل لـ PDF لسا شكلي |
| روابط اختبارات IELTS/TOEFL | ✅ روابط حقيقية (British Council / IDP / Amideast) |
| دليل الجامعات، متابعة الملف، مستنداتي | 🧪 بيانات تجريبية ثابتة بالكود |
| ربط البريد الجامعي | 🧪 محاكاة — يحتاج ربط OAuth حقيقي (Google/Microsoft) لاحقاً |
| مجتمع الطلاب | 🧪 محاكاة — يحتاج تحقق حقيقي من الإيميل الجامعي وباك-إند |
| الإشعارات | 🧪 بيانات تجريبية ثابتة |

قبل الإطلاق الفعلي لازم:
1. تبديل روابط الإحالة في `AFFILIATE_LINKS` بروابطك الحقيقية بعد موافقة الجهات.
2. ربط باك-إند حقيقي (قاعدة بيانات + مصادقة) بدل البيانات الثابتة (`UNIVERSITIES`, `DOCS`, `STEPS`, ...).
3. تفعيل تحويل الصور إلى PDF فعلياً (مثلاً عبر `expo-print` أو خدمة سحابية).
4. تفعيل تسجيل الدخول الحقيقي بدل الأفتار الثابت "خ".
