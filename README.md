# Teekafit

مشروع تطبيق للياقة البدنية والتغذية (Teekafit) — تمت استعادة هذا المحتوى من نسخة احتياطية تم سحبها من Manus بعد حذف المشروع السابق بالخطأ.

## المحتوى

### `teekafit-app/`
**كود المشروع الفعلي** (Full-stack TypeScript: React 19 + Vite + Tailwind + shadcn/ui من جهة العميل، Express + tRPC + Drizzle ORM (MySQL) من جهة السيرفر، مصادقة عبر Manus OAuth).

بُنيت عليه أول نسخة تعمل فعليًا وتم اختبارها بتشغيل السيرفر وتصفّحها بمتصفح حقيقي:
- **شاشة ترحيب متحركة** بشعار "Tt" وتأثير نبض أخضر نيوني (`components/TeekafitSplashScreen.tsx`).
- **لوحة تحكم رئيسية**: تحية حسب الوقت، شريط تقدم السعرات، عداد الأيام المتتالية (Streak).
- **جدول التمارين اليومي**: تمارين بسِت/تكرار، تحديد كمكتمل، ونظرة على جدول الأسبوع.
- **متتبع التغذية**: شريط تقدم للسعرات والبروتين/الكارب/الدهون، وإضافة وجبة جديدة عبر نافذة منبثقة.
- **مكتبة تمارين**: بحث وتصفية حسب المجموعة العضلية.
- **قاعدة بيانات (Drizzle/MySQL)**: جداول `exercises`, `workoutPlans`, `workoutPlanExercises`, `mealLogs`, `nutritionGoals`, `streaks` مع العلاقات بينها.

⚠️ **مهم بخصوص الحدود الحالية:**
- الشاشات الأربعة **غير مربوطة بأي backend** — البيانات محلية بالكامل في `client/src/data/teekafit.ts` وتُفقد عند تحديث الصفحة.
- **المصادقة (تسجيل الدخول) غير مفعّلة**: السكافولد فيه Manus OAuth جاهز، لكن بيئة العمل هذي ما فيها `OAUTH_SERVER_URL`/`VITE_APP_ID`، فتركت الشاشات مفتوحة بدون قفل دخول مؤقتًا.
- جداول قاعدة البيانات مكتوبة لكن **لم تُهاجَر فعليًا** (تحتاج `DATABASE_URL` لتشغيل `pnpm db:push`).

راجع [`teekafit-app/todo.md`](teekafit-app/todo.md) للخطة والحالة التفصيلية، و[`teekafit-app/package.json`](teekafit-app/package.json) للتشغيل (`pnpm install` ثم `pnpm dev`).

- **مقترحات تسمية مشروع اللياقة والتغذية العالمي.md** — مقترحات أولية لاسم المشروع.
- **مقترحات أسماء رياضية رنانة (Global & Punchy).md** — أسماء بديلة ذات طابع عالمي وقوي.
- **تحليل اسم "Teeka" لتطبيق اللياقة والتغذية.md** — تحليل تفصيلي لاسم "Teeka" المُختار.
- **ابتكارات تجربة المستخدم (UX) لواجهة الترحيب في تطبيق Teekafit.md** — أفكار لتصميم شاشة الترحيب (Onboarding/Splash).

### `components/`
مكوّن الكود الأصلي (React + Tailwind) لشاشة البداية كما وصل من مانوس، قبل تحويله إلى TSX ودمجه داخل `teekafit-app/`:

## ملاحظة

عندنا الآن نسخة أولى شغّالة فعليًا من التطبيق (`teekafit-app/`)، بالإضافة إلى المستندات البحثية والأصول التصميمية. الخطوة التالية المنطقية: ربط الشاشات الأربعة بقاعدة بيانات حقيقية عبر tRPC بدل البيانات المحلية، وتفعيل تسجيل الدخول عند توفر متغيرات OAuth.
